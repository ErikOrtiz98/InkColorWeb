Business Web Platform

Sitio web desarrollado para un negocio familiar enfocado en presencia digital y centralización de información comercial.

Funcionalidades

- Visualización de productos y servicios
- Información comercial
- Navegación responsive
- Formularios de contacto
- Gestión básica de contenido

Tecnologías utilizadas

- HTML
- CSS
- JavaScript

Objetivo del proyecto

Desarrollar una solución web funcional orientada a mejorar la presencia digital y facilitar el acceso a información para clientes y usuarios.

Experiencia obtenida

- Desarrollo web orientado a usuarios reales
- Diseño responsive
- Organización de contenido
- Mantenimiento y actualización de sitio web
